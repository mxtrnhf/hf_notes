# `rep-audit-2026-10-29.tsv` — consolidated `rep_*` audit (batch 6; rebuilt in batch 7)

One row per `rep_*` function the batch-6 and batch-7 re-match agents inspected. Columns
(tab-separated, no quoting; do not add tabs inside a field):

```
addr<TAB>old_label<TAB>verdict<TAB>new_name_or_identity<TAB>evidence
```

* `addr` — function entry, hex with `0x`.
* `old_label` — the `rep_...` name as it was before the pass (the stale
  embedded target, e.g. `rep_140057220_..._sqrtf`).
* `verdict` — the values actually used by the four agents: `renamed` (body
  proved a new name, applied and plated), `stale label` (body contradicts the
  embedded label; recorded, not renamed) or `unreadable` (bytes could not be
  hashed).
* `new_name_or_identity` — the applied name, or the identified-but-unapplied
  identity, or `-`.
* `evidence` — the shortest decisive proof (hash twin, callee, string, vtable
  slot, RTTI).

Rebuild with (from `hf_notes/docs/data`; skips a header only when the first
field really is `addr`, normalises `0x`, keeps the newest row per address and
sorts by address):

```sh
python3 - <<'PY'
import collections
rows = {}
for q in (1, 2, 3, 4):
    try:
        f = open(f'rep-audit-2026-10-29-q{q}.tsv')
    except FileNotFoundError:
        continue
    for line in f:
        p = line.rstrip('\n').split('\t')
        if not p or p[0].strip().lower() == 'addr':
            continue
        a = '0x' + p[0].strip().lower().removeprefix('0x')
        rows[a] = p          # later row wins
out = sorted(rows.items(), key=lambda kv: int(kv[0], 16))
with open('rep-audit-2026-10-29.tsv', 'w') as g:
    g.write('addr\told_label\tverdict\tnew_name_or_identity\tevidence\n')
    for a, p in out:
        g.write('\t'.join([a] + p[1:]) + '\n')
PY
```

Earlier merges were not de-duplicated. If the same address appears twice (two
agents looking at it from different sides, or a batch-7 re-match of a batch-6
row), the later file/row wins; that is why the order q1 -> q4 matters.
