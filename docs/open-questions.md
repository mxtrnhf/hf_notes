## Blind re-derivation of foundations
Three agents with no access to these notes re-derived the ammo record, the Body layout and the world/Creature/stats layouts from the 1.163 program (read-only). **Independence caveat:** the agents never saw these notes but did see the Ghidra database (names such as `ammo->ttl`) and field names in their prompts, so this is independent of the notes' text, not of Ghidra's labels. Trust their offsets over their constants (one report lists AP penetration 33 where the scripted parse has 34, and omits 180mm from its lifetime list). **Agreed with the notes:** ammo stride `0x188` and the field offsets (incl. `+0x150` logic id stored by `BulletImpact__`, `+0x154` the `FireShell` key, `+0x16c` ttl, `+0x180` burst), the weapon-part link (stats `+0x144` equals ammo `+0x154`, `FireGun` passes part `+0x850`), Body size `0xa40`, class code `+0x28`, id `+0x78`, owner `+0xb0`, health `+0x2c8`, logic `+0x3c4`, weapon keys `+0x84c..+0x85c`, the world vectors (fleets `+0x1f8`, missiles `+0x228`, MapCrafts `+0x270`), ship fuel `+0x1638/+0x1640` (double), crew `+0x17ec/f0/f4`, radius `+0x1850`, and the stats record (`+0x16c` is the float `m_missile_explosive_cluster`). **Open:** (a) shop price `+0x170`: confirmed for one item only (130mm guided: table 200, shop 200, 15 bought = 3000 gold; probe run 2), no reader instruction found; (b) `+0x174` / `+0x178`: values fit rarity / amount, effect untested; (c) Body `+0x800` / `+0x804`: the fuel half (`+0x7f8`, double) is confirmed live, but `m_mdl_fss` and `m_mdl_crew` read 0 on every part, probably because crew is only assigned in the campaign [guess]; Body `+0x28` was `0xf` on all 10 held parts [game]; (d) `creatureLogic` case bodies (the decompiler times out); (e) Profile `+0x1b0/0x1b8/0x1e0/0x1e8` contents; (f) Creature `+0x17cc/+0x17d4`; (g) Body links `+0x80` vs `+0x98` master/second-link naming. Method note: a bad label reaches the notes through Ghidra names, so prefer checks that do not go through them (save keys, `.seria` data, other people's layout tests, a runtime read).
