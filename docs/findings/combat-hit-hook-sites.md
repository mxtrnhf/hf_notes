## Birth rows for rockets, harpoon and Zenith; AI gun decision rows (added 2026-10-23, second request from probe-dev)
All bytes read from the image, none run. "Entry" = function entry. Stolen instructions are whole and have no rip-relative operand.

### Which function creates what [V]
* `FireShell 0x1400300d0` creates every gun-fired projectile. Its caller `FireGun 0x140032e60` calls it at `0x140032f99` with `RCX` = the gun part, `RDX` = pointer to the muzzle/direction vec2, `R8D` = **the gun's ammo key, `[gun +0x850]`**, `R9D` = side tag (stored at body `+0x204`), `[RSP+0x20]` byte = recoil flag (1), `[RSP+0x28]` int, `[RSP+0x30]` float, `[RSP+0x38]` = 0. Entry stub (**function entry**): steal `48 8b c4 44 89 48 20 48 89 50 10 48 89 48 08` (15 bytes). It logs the shot (gun, ammo key, side) but not the new body.
* Dispatch is a byte table: case = ammo key mapped through `key - 5` (cases 0..14 = keys 5, 10, 15, 20, 25, 30, 40, **51, 52, 54, 55, 60, 70, 80, 90**). Plain shells (5..40) and the **harpoon (90)** go through `BulletImpact__ 0x140052a80` (7 call sites in `FireShell`: `0x140030405, 0x14003058c, 0x1400306e4, 0x140030822, 0x140030941, 0x140030a5b, 0x140030ba7`; the last is the harpoon, followed by the store of logic `0x89` (137) into the *gun part* at `0x140030c91`). **Rockets 51, 52, 54, 55 do NOT use `BulletImpact__`**: they build the body inline in `FireShell` (`Body::Body` -> `CreateShell?` `0x14004edd0` -> level node vtable `+0x50` -> field stores). Canister 60 / 70 and EMP 80 are further inline blocks (not hooked here).
* The Zenith (`MDL_MISSILE_01`, logic 1) is **not created**: it is a ship part that detaches (`LaunchZenithAtOwnerTarget` arms it, `creatureLogic` ejects it). The multicharge launch `FUN_14002e3a0` and the player launch `FUN_14002e590` likewise only arm a part; there is no body-creation call in any of them.

### 2. `AiWeaponController 0x14007a8d0` per-gun rows (entry = function entry)
The function takes the **creature** (`RCX`, kept in `RDI`) and loops over the guns itself: it is not called per gun. Entry stub: steal `40 55 53 57 41 54 41 55 41 56 41 57` (12 bytes, 7 whole instructions). Three FireGuns shapes (weapons-index 3.2). `RBX` = the gun part inside every loop, `RSI` = list cursor, `[RDI+0x13a8..0x13b0]` group 0, `[RDI+0x13c0..0x13c8]` group 1.
| Shape / group | Loop-top site (gun `RBX` live) | Bytes | What is live |
|---|---|---|---|
| **C ship target, group 0** | `0x14007b99e` | `48 8d 54 24 60` | `RBX` gun, `RDI` creature, `XMM9` = aim angle that is about to be sent (`[RSP+0x64]` is set at `0x14007b9a3`; command code 200), `XMM8` = distance (aim point, the value gated), `XMM15` = 0, `R13` / `R12` = the shape-C exception flags (aircraft link and group-1-empty). |
| **C group 1** | `0x14007bc77` | `48 8d 54 24 60` | same |
| A aircraft/missile target, group 0 | `0x14007abc7` | `48 8d 54 24 60` | `RBX` gun; `XMM0` = jittered angle (`rand(-0.3,0.3) + XMM12`) stored at `0x14007abef` (6 bytes `f3 0f 11 44 24 64`: steal this instead to read it from `XMM0`) |
| A group 1 | angle store `0x14007ade0` (`f3 0f 11 44 24 64`) | | `XMM0` = jittered angle sent to `RBX` |
Gate values (shape C; the compare + `Jcc rel32` pairs are not stealable, so hook the **instruction just before the compare**, which is a plain `movss`):
* gate 1 latch: `[RBX+0x875]` (read at the loop-top site); gate 2 loaded: `[RBX+0x860]`; burst timer `[RBX+0x870]`; magazine `Stats([RBX+0x188])+0x148` (`GetStats 0x140281e00`).
* gate 3/4 inputs: `[RDI+0x228]` (byte), distance `XMM8`, calibre key `Stats+0x144`; limits 700 (`0x140352840`) and 1500 (`0x1403548b0`).
* **gate 5 range** site `0x14007ba70` (group 0) / `0x14007bd3d` (group 1): `f3 0f 10 8f 38 18 00 00` / `f3 0f 10 8f 3c 18 00 00` (8 bytes, `movss xmm1,[rdi+0x1838 / 0x183c]`). At that point `XMM8` = distance, `[RBP+0x70]` = byte `local_res8` (0 means the limit is doubled), so `limit = [RDI+0x1838 / 0x183c] * (byte == 0 ? 2 : 1)` and the gate stops the gun when `XMM8 > limit`.
* **gate 6 angle** site `0x14007ba8e` (group 0) / `0x14007bd5f` (group 1): `f3 0f 10 b3 38 01 00 00` (8 bytes, `movss xmm6,[rbx+0x138]`). Gun angle `[RBX+0x138]`, aim `XMM9`; value = `|wrap(gun - aim)|` with `wrap(x) = x - 2 pi * round(x / 2 pi)`, gate stops when it is `> 0.025` (`XMM12`, `0x140354678`). Reached only if gates 1-5 passed.
* gate 7 (friendly fire, `FUN_14021c790`) has no stealable instruction (the neighbours are rip-relative or `Jcc rel32`): infer it as "passed gates 1-6, did not fire, did not start": the fire/start events below tell.
* gate 8 / start events: group 0 latch store `0x14007bc2c` (`c6 83 75 08 00 00 01`, 7 bytes) and group 1 `0x14007bef6` (same bytes): run only when a normal start happens. Exception path (no pause, no latch): `0x14007bbf6` (group 0, `c7 83 70 08 00 00 00 00 00 00`, 10 bytes) and `0x14007bebe` (group 1, `44 89 a3 70 08 00 00`, 7 bytes, `mov [rbx+0x870],r12d`).
* **Fire event** (any gate path that calls `FireGuns`): hook `FireGuns` entry `0x1400559e0` and read the return address `[RSP]`: `0x14007bc3b` (shape C group 0), `0x14007bf05` (shape C group 1), `0x14007ad67` (shape A group 0), `0x14007af44` (shape A group 1; computed from the call at `0x14007af3f`). `RCX` = gun. This is the single reliable "fired" marker; the latch path (gate 1) calls `FireGuns` from the same site.
* **Gun `+0x850` ammo choice stores** (group 0 ammo loop, calibre keys 15, 20, 25, 30): `0x14007b488`, `0x14007b4f8`, `0x14007b568`, `0x14007b5d8`, each `89 83 50 08 00 00` (6 bytes, `mov [rbx+0x850],eax`), `EAX` = the `FindAmmoIndex` result, `RBX` = gun.
**One site that records the gate number:** not possible without changing code: all failing gates jump to the same loop tail (`0x14007bc3b` group 0, `0x14007bf05` group 1). Recommended row per gun per call: at the loop-top site record (gun, latch, loaded, burst timer, aim `XMM9`, distance `XMM8`, creature `RDI`); at the gate-5 and gate-6 sites record the limit and the angle value (their presence tells how far the gun got); at the `FireGuns` return-address marker record "fired"; derive the gate number offline: not fired and (latch 0 and `loaded <= 0` -> gate 2; `+0x228` and dist > 700 -> 3; calibre <= 10 and dist > 1500 with `FUN_1402213e0` -> 4; no gate-5 row or dist > limit -> 5; no gate-6 row or angle > 0.025 -> 6; gate-6 passed, no start event -> 7 or 8 (8 if loaded < magazine)).
