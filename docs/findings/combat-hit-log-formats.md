# Combat event log: `hf_ally_hit_<id>.csv` row formats (hf_ally sim.49 / sim.50), probe-dev, 2026-10-23

hftm kind `hit` (packed automatically). Needs `probe_hooks` on. All rows start `t,step,kind,...`; `step` = the physics step counter shared with the hook/swivel logs (see below for births). At most 600 rows per step. The file's own `#` header repeats this list. **Untested in play at the time of writing**: sim.49 hooks C/A/P, sim.50 adds S/K/M/Z/Y. Hook sites and register maps: `combat-hit-hook-sites.md` (ghidra-curator).

Common body fields (17, in this order, used by C): `P` (pointer), `ship` (telemetry id, 0 = player, -1 = not a tracked ship part, -2 = lock busy), `part` (part number within the ship, -1 none), `cls` (+0x28), `logic` (+0x3c4), `oid` (+0x190 string), `expl` (+0x2dc), `hp` (+0x2c8), `hpmax` (+0x2cc), `arm` (+0x38c, detonation threshold in I units, -1 = not armed), `st` (+0x3cc), `ttl` (+0x3d0), `mass` (+0x1d8), `x`,`y` (+0x128/+0x12c), `vx`,`vy` (+0x130/+0x134), `owner` (+0xb8 creature pointer).

| kind | when | fields after `t,step,kind` |
|---|---|---|
| **C** | `Physics_ProcessContactRecord` 0x1402849a0, only when a body has logic 100/130/132/135/140/160/190 | `rec, imp_raw (rec+0x40, b2 SI), I (=raw*160000, game units), dmg_d (=0.8*raw)`, then the body fields for body A (rec+8), then for body B (rec+0x20). Detonation test is `0 <= arm < I`; it fired iff a D row (hf_ally_hook, ret rva 0x1d32c) appears in the same step. |
| **A** | every `Body_ApplyDamage` 0x1400519d0 call | `body P, ship, part, logic, d, p3 (armour-check flag), p5 (hull-hull byte), p6 (defer), hp before, hpmax, stats index (+0x188), ret rva`. Armour gate: skipped when `p5==0 && p3!=0 && d < Stats(idx)+0xc4` (join the threshold from simparts S rows). Contact damage has ret rva inside 0x2849a0..0x2860xx, blast damage inside 0x2cdc0... |
| **P** | the hp store 0x140051e09 (damage reached the store) | `body P, ship, part, logic, hp before, hp after`; after 0 = Body_DieExplode follows. A skipped call = A row without P row. |
| **S** (sim.50) | a shell is created (`BulletImpact__` 0x140052a80); written at the ENTRY of the physics step that first moves it, `step` = that step's number | `shell P, ammo index (Ammo+0x154), ammo name (Ammo+8), ammo logic (+0x150), ammo speed (+0x158), ammo ttl (+0x16c), shooter ship, side tag, aimed target P, target ship, target part, firing ship body P, gun P (0 if FireGun 0x140032e60 was not seen in the same step), gun ship, gun part, dir x, dir y (vec2 the caller passed), x, y, vx, vy, ang (+0x138), ttl (+0x2c0), hp, expl, pen (+0x2e0), mass, logic`. Covers `BulletImpact__` only: missile/rocket launches (LaunchZenith..., logic 130/132/135) go through other creators and are NOT in S rows yet. |
| **K** (sim.50) | blast starts (`FUN_140029b60`) | `exploding body P, logic, x, y (+0x148/+0x14c), E (+0x2dc), S (+0x2e0), kind (+0x2e4), incend (+0x2e8), R (+0x20c), shooter ship (0 = player), hit-body P (+0x3b0), hit ship, hit part`. Which of +0x2e0 / +0x20c is the game's "S" and "R" is not confirmed: raw values are logged. |
| **M** (sim.50) | a part is offered to the blast (`Body_AreaDamageFromBlast` 0x14002cdc0) | `part P, ship, part, shell P, scale (visibility*S, XMM2), R (XMM3), centre x, centre y, hp before, hpmax`. The damage it deals follows as A (ret rva in 0x2cdc0..) and P rows. |
| **Z** (sim.50) | a ship part is removed (`Body::KillAndQueueDead` 0x1402805e0, ship parts only) | `part P, ship, part, logic, part mass (+0x1d8), removeFromMaster, creature mass (+0x15b8) before, part hp` |
| **Y** (sim.50) | 1 and 10 steps after a Z, once per ship | `ship, d (steps after), creature mass (+0x15b8), b2 mass kg of the root body (b2 +0x90), b2 inertia (+0x98), b2 local centre x, y (+0x1c/+0x20), game mass derived (= b2 mass / 0.05^3)`. The game may update the b2 mass late; compare d=1 and d=10. Root body = creature +0x88 if its class nibble is 0xf, else the creature. |

## sim.51 additions (rockets, missiles, AI gun decision)
| kind | when | fields after `t,step,kind` |
|---|---|---|
| **R** | a gun-fired rocket is born (FireShell keys 51/52/54/55, logic 130/132), written ONE step after the birth site so velocity is valid | `body P, logic, ammo index (key, Ammo+0x154), ammo name, shooter ship, side tag, gun P, gun ship, gun part, target P (+0x498, usually 0 for rockets), target ship, target part, x, y, vx, vy, ang, ttl (+0x2c0), hp, expl, mass, creature mass (+0x15b8) of the owner, born step` |
| **L** | a part-launched missile detaches (Zenith MDL_MISSILE_01 logic 1; the ejection block is shared with logic 3, 4 and 132) | same columns as R; ammo index -1, ammo name empty, "gun" = the missile part itself with ship/part -1; target = the armed target link (+0x498). Use it with the creature mass (+0x15b8) column: compare with the mass of the preceding rows to see the per-launch drop. |
| **G** | AiWeaponController loop top, shape C (ship target), once per gun per call | `group (0/1), creature ship, gun ship, gun part, latch (+0x875), loaded (+0x860), burst timer (+0x870), aim angle sent (XMM9), distance (XMM8), gun angle (+0x138), ammo key (+0x850), creature byte +0x228` |
| **G5** | the range test was reached for that gun | `group, gun ship, gun part, dist, limit (creature +0x1838/+0x183c), limit byte ([rbp+0x70], 0 = limit doubled), effective limit`; the gun is stopped when dist > effective limit |
| **G6** | the angle test was reached | `group, gun ship, gun part, gun angle, aim angle, wrapped |diff|`; stopped when > 0.025 |
| **GS** / **GE** | latch store (a normal fire start) / the no-pause exception store | `group, gun ship, gun part` |
| **GA** | ammo choice store | `gun ship, gun part, ammo index` |
| **F** | every FireGuns call (also player guns) | `gun ship, gun part, caller rva`: 0x7bc3b = shape C group 0, 0x7bf05 = C group 1, 0x7ad67 = A group 0, 0x7af44 = A group 1 |
Gate number 1-8 is derived offline with the rule at the end of `combat-hit-hook-sites.md` (section 2). Shape A (aircraft/missile target) angle stores are not hooked, only shape C. Harpoon (key 90) births are the normal S rows (ammo index 90). The row cap is now 2000 per step.

Not done: 50 Hz shell positions, shape A gun rows, Stats +0xc4 threshold column (use simparts).
If hf_probe's `hook_blast` is on it patches `Body_ApplyDamage` too; hf_ally loads first and wins, the probe then skips its DMG hook.
