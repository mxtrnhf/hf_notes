# highfleet-elevation  (repo `hf_elevation`, published)

Sets the **elevation** (`m_floor`) of the part held in the shipworks. Elevation decides who can block whom in arc/exhaust scans (`../systems.md`), so combined with
highfleet-qol's restored gun-arc blocking you can design guns that fire over your own hull.

* Keys while holding a part: **U** raise, **P** lower, **\\** give back to automatic (then drop it so the game recomputes). A text overlay shows floor, manual/auto, neighbours.
* Config `elevation.ini`: `max_floor`, `sync_children` (mounted parts follow their mount; otherwise a gun is buried under a raised block), `child_offset`, `overlay`.
* Mechanism: reads the editor's held-part pointer (global `0x1403c0d88`; editor-active flag `0x1403ef368`), clears bit `0x01` of `m_floor_type` (+0x9b0) and writes `m_floor` (+0x9b8). Polling, no detour.
* A ship saved with manual floors loads the same without the mod (the game honours saved values).
* Status: works [game]. Overlay is a separate transparent window (may not show in exclusive fullscreen). Other editor functions: wheel `FUN_1400bc5e0`, rotate `FUN_1400bdad0`, place `FUN_1400bbbf0`.
* **QoL port (2026-10-14, fork branch `elevation`; upstream PR #20, draft, stacked on #19):** section `elevation` of `qol.json` (`enabled`, `max_floor`, `sync_children`, `child_offset`, `overlay`, `keys.raise`/`lower`/`auto` as key names such as `U`, `F5`, `Backslash`). 1.163 only. The user installed the DLL and reported it works [game]. In this first version it was a polling thread plus a GDI overlay window; the native in-game hint that followed supersedes the overlay (next paragraph; [findings/render-pipeline.md](../findings/render-pipeline.md)). Remove the standalone `elevation.dll` when using it; `elevation.ini` is no longer read.
* **Native hint (2026-10-14, QoL fork branch `elevation`):** the readout is now drawn inside the game by wrapping the editor label-pass call at `0x140303fb4` (see [../findings/render-pipeline.md](../findings/render-pipeline.md)), with the game's own font `fixed_16` (white, scale 1.0, right-aligned at x=1880, y=24 of the 1920x1080 frame; first tried `dinpro_14_bold`, too bold) [game: user confirmed it appears in all editor states]. Setting `hint` in the `elevation` section: `native` (default), `window` (the old transparent overlay window and polling threads, also the automatic fallback when the hook site bytes do not match, e.g. when another mod patched it [game]) or `off` (keys still work, nothing drawn). In `native` mode key polling and floor writes run in the same hook on the game thread; keys only react while the game window has the keyboard focus. Font notes: [../findings/fonts.md](../findings/fonts.md).
