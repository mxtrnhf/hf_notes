# Highfleet 1.163 reverse-engineering notes

One reference for everything learned while building the Highfleet mods below: tooling, data formats, the Body (ship part) layout,
elevation and firing arcs, the map speed formula, multi-charge parts, missile launching and fighting, salvos, refueling.

* [NOTES.md](NOTES.md): the notes (addresses are for the Steam 1.163 build, image base `0x140000000`).

Mods built on these notes:
[highfleet-elevation](https://github.com/mxtrnhf/highfleet-elevation),
[highfleet-speed](https://github.com/mxtrnhf/highfleet-speed),
highfleet-multicharge, highfleet-salvo, highfleet-refuel.
Everything runs on [Highfleet-Modloader](https://github.com/logdot/Highfleet-Modloader).
